Privacy Policy

Last updated: 17 November 2026

Briefing Agent is a personal application used only by its owner. It is not offered to other users.

What data it accesses

With the owner's permission, the app uses read-only access to the owner's Gmail account (the gmail.readonly scope) to read recent emails. It cannot send, delete or modify emails.

How the data is used

Email content is used only to generate a private daily summary for the owner on the owner's own computer. A summary request containing excerpts of these emails is processed by an AI assistant service the owner subscribes to.

Storage and sharing

Access tokens and generated summaries are stored only on the owner's computer. No data is sold, shared with third parties for advertising, or used for any purpose other than the owner's personal summary.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
